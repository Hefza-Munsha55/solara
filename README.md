## Problem We Solve

Pakistan faces 8-12 hours of load shedding and electricity bills have increased by 150% in 2 years. Middle-class families need an affordable, reliable, and beautiful solar solution made for local conditions like 70°C summer heat, dust, and monsoon humidity.

## Solution

SOLARA is not just another solar site. It is a complete sales funnel:

1.  **Awareness:** Hero section with clear value prop (Save up to 95% on bills)
2.  **Trust:** Stats (12k+ homes, 22.8% efficiency, 25Y warranty), reviews, bank financing
3.  **Conversion:** 3-tier pricing with a highlighted "Most Popular" plan + 1-click order modal via WhatsApp

## Tech Stack & Architecture

This project uses **Vanilla Stack for Maximum Performance** in Pakistan where 3G/4G speed is still an issue. No heavy frameworks.

- **Frontend:** Semantic HTML5, Modern CSS3 (Grid, Flexbox, Glassmorphism, Custom Properties)
- **Logic:** Vanilla JavaScript (DOM, Event Delegation, Scroll API)
- **Typography:** Plus Jakarta Sans (UI) + Fraunces (Display) for premium feel
- **Performance:** Single image, no libraries, <50KB total size

## Design System

A consistent design language was built before coding:

- **Colors:** Background `#FFFBF2`, Primary `#1A1A1A`, Accent `#FFC900`, Muted `#7A7A7A`
- **Spacing Scale:** 8px, 16px, 24px, 32px, 40px
- **Radius Scale:** 12px (cards inner), 24px-28px (cards), 100px (buttons/pills)
- **Shadows:** Soft, layered shadows for depth without heaviness

## Responsiveness

Tested on Chrome DevTools for real devices:

- **Desktop (1220px):** 2-column hero, 3-column features, 3-column pricing
- **Tablet (900px):** Stacked hero, 2-column products, full-width popular card
- **Mobile (390px - iPhone 14):** Single column, 38px headline, full-width buttons, sticky hamburger menu
